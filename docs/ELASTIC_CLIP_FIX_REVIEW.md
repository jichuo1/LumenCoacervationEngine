# 长按形变截断修复

基准是已发布的 LCE 1.2.4，保留 1.2.3/1.2.4 的视口停止、面板圆角、真实布局高度与裁剪归还修复。公开 API、契约版本、手势阈值、原生点击及滚动分发均不改变。

## 证据与原因

BIL 的来源行由 `createSemanticSourceRow` 委托 `createGitHubMenuRow` 构造，位于 `MaxHeightScrollView -> body -> row`；`MaxHeightScrollView` 明确继承平台 `ScrollView`。行填满视口宽度，高光绘制在命中行的 overlay。旧行程只取直接父容器内容坐标，并保留最低位移预算；最终拉伸又围绕 pivot 扩大外缘。普通 body 虽然暂时解除裁剪，上层视口仍正确保留裁剪，因此外扩区域被齐切。

在 Android 37 实际设备上，用真实长按捕获和同类填满宽度的行复现，修复前左边缘越界 `-14.87088 px`。测试先验证真实 CANCEL/拖动捕获，避免未触发手势时的假通过。这个结果证明矩形视口链路；不能单凭用户截图推断全部运行时视图状态。

三个研究组并行检查了几何、旧修复回归和容器差异，成员来自 ZCode、OpenCode、Claude 与 Antigravity。报告中假设缺失函数任意返回非法提升深度、把横滚当本截图必要条件等推断经完整源码核对未采纳。官方网页采集缺少正文的报告也未当作 Android 契约证据。

## 实现

- 按下时逐层换算布局、原始平移与每层滚动偏移，记录真正保留的裁剪交集；回抓使用原始 lease 与先前 clip flags。
- 最终绘制前同时限制平移与围绕 pivot 的拉伸，保留有空间控件的原响应；全宽贴边方向收紧行程。
- 圆角 outline 以实际矩形和半径限制四个绘制角。越界时沿原始几何到请求几何的连续路径收敛，避免只限制外接矩形仍切入圆角。
- 没有公开可读几何的可裁剪路径采用原始几何；原有 clipToOutline 和裁剪路径继续工作。自绘且没有声明边界的任意 clipPath 不在自动解析范围内。
- `clipToPadding` 全零时不制造不存在的裁剪。最终变换写回同一 lease，使用原材质位置通知；逐帧复用数组和向量，不增加离屏层、位图或反射。

## 验证边界

新增纯函数测试覆盖全宽、留白、偏心 pivot、无界包裹、原有部分裁剪、数值错误、弹簧过冲和圆角。设备用例覆盖左右/上下/对角拖动、padding+scroll、部分可见行，以及圆角视口。

原 `PanelClipContainmentTest` 的裁剪、归还和稳定圆角像素断言保留。夹具改为固定像素字体、确保内容不被 ScrollView 的无限测量缩成紧包裹，并将触点移离高密度设备的系统边缘手势区；没有放松断言。

实际执行记录保存在宿主的本地验证目录，包含修复前失败、候选设备结果、引擎与 BIL 门禁。BIL 开发源验证副本只按宿主既有规则对齐工具链；motion 生产源码逐文件哈希一致。正式 1.2.4 标签和宿主正式归档锁不改写。

当前设备 BIL 使用固定发布签名，本地 Debug 验证包签名不同。通过现有正式签名流水线发布并更新宿主不可变版本锁之后，才能覆盖当前 BIL；不得以卸载或更换签名绕过。设备示例验证不等同于所有 Android 版本或当前安装 BIL 面板的最终验收。
