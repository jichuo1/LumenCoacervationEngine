# 1.4.2 修复与发布审阅

本次汇总此前的性能与稳定性修复，以及六项经反证复核的动效一致性优化。源码基线为 `9ec28ca94d38d1a36857d629c27b16d898075b00`；各步完成后独立 review，再推进下一步。

## 行为变化

- 持久化确认后交付材质失败通知；背景写入、修复和回滚按代次确认，避免并发覆盖及配置引用已删除资产。
- 清理自有播放器生命周期、包装层、Chrome 监听与边缘视图、旧高光及页面缓存；恢复可见效果调度、首个来源观察与热预算，分配失败统一挂起性能资源。
- 排序回位异步、每次一次交付，等待交叠拖拽完成，保留清理时的位置快照和迟到空参数兼容。
- 面板按真实轴向准备竖向回弹，横向与双轴保留平台行为；未知轴等待布局证据，拆除后不再安装。
- 横向定位接管平台旧惯性，通过可选适配器停止第三方滚动；按实际两轴位置和边界验收，在主队列交付前复核，漂移时继续同一请求。
- 三种形变与翻页将真实秒速度和系统倍率换算后的实际时长匹配。长导航另修正 420ms 切线截断，拖拽仍保留 420ms。
- 关闭系统动画后，局部按压在后续事件或既有/手动帧清理；装饰角标指南保持正常命中，自管手势继续排除。

## 逐步复审

六项均通过独立 review。复审先复现并修正了移除布局监听后仍被 VTO 快照调用、目标移出原树后的迟到动画帧写入，以及交付前纵向位移导致定位挂起；同一生产类探针反向通过。

U01 有 61 个受控边界检查。U05 的 408 个普通路径对象状态快照与本轮基线逐点一致；U04 的短导航 6,054,048 点与长拖拽 560,560 点位级一致。U03 相对 U04 完成状态的 3,203,200 个 1 倍 Page 样本一致，并验证真实 Bubble 控制器的续速与旧轨迹。U02 的 40 条受控矩阵记录、23 项定向测试及旧二进制调用通过。

这些探针使用真实生产类，Android 调度和部分平台边界采用受控替身。它们证明指定输入下的算法、接线与生命周期行为，不代表设备或 GPU 像素等价。

## 兼容与保留范围

新增 `LumenReveal.setHorizontalScrollMotionStopper` 与 `LumenControls.stopScroll` 为兼容可选入口；旧构造与 Kotlin 默认参数描述符经 `javap` 及预编译调用者验证。该适配仅用于最近横向容器，纵轴 RecyclerView 仍遵循既有坐标闭环能力。

契约版本仍为 1，minSdk27、构建和依赖钉点保持。未改 shader、光学常数、弹簧参数、默认 Rive Canvas 或既有裁剪/采样修复。此前撤回的严格采样预算取整修复保持撤回；U03 的 1 倍保持不包含 U04 对长导航非零初速的有意纠正。

## 验证边界

当前云环境没有 adb 设备或可用 KVM，未进行本次真机/OEM、GPU 像素、原生堆长时压测和系统倍率通知时序验证。Demo 安装包沿用仓库独立设备测试与上传流程；此文档不预先声明远端测试、附件上传或 JitPack 已成功。

API27–32 的公开设置值与进程动画倍率存在通知短窗；倍率读取后的再次变更、极小倍率截断及既有速度/空间/最短时长限制不保证任意初速完全连续。局部按压没有新增全局设置监听。未接入停止适配器的第三方容器不能保证排他停止原生惯性。

持续磁盘写失败时保留可能仍被引用的文件是避免悬空引用的策略，不能保证此时磁盘占用固定。首次未知裸列表延期包装后可能保留原 engine outline 与新视口 outline 共存；其 HWUI 像素效果仍需设备核验，未按推断解除既有裁剪。

发布状态与实际产物校验以对应 Release 的 `VERIFICATION_1.4.2.json` 和 `SHA256SUMS.txt` 为准。
