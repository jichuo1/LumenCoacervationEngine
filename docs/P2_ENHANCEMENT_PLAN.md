# 下一轮视效强化执行计划

基线：已发布1.2.0，8839f2e。原研究报告D14/D20/D21为本轮默认范围。
继续保留1.2公开构造、持久化标识和默认外观，不修改已发布标签。

1. D14：motion层可选传感器光源输入。默认关闭，显式start/stop；窗口/显示方向映射、dt滤波、平放阈值、角速度/更新率上限；缺失与后台状态可见。生产者不接管业务触摸或自动启动全进程传感器。
2. D20：独立lumen-effects模块，包含薄膜、纸张、有限时长能量纹理。编译期已知效果，不接收任意网络Shader；不读背景的生成器没有捕获资源。
3. D21：固定池粒子。确定性种子/时钟、数量/面积/寿命/速率预算，结束/隐藏/后台停止调度，保留低版本Canvas回退。
4. 可逆View overlay接入和参数预设，Demo给足中文开关与数值调节、固定步进、诊断及导入导出。
5. 数学/状态JVM、所有权/生命周期设备与实际像素、低版本DEX、ABI、完整构建/Lint、最终Review。

6. 用户已选择D22并批准三个生产依赖：Lottie6.7.1、PAG4.5.98-noffavc、Rive11.14.0。增加统一lumen-assets契约及三个独立播放模块；核心不引入它们的传递依赖。

Compose不属于本轮接入范围；Rive SDK自身的Compose传递依赖仅存在于选择了Rive播放模块的宿主中。
NativeBackdrop与Mesh仍为观察项，不默认进入生产路径。
传感器事件的模拟验证与真机能耗/多显示器验收分别记录。

本轮执行状态：D14/D20/D21/D22实现及本地Review完成；747项JVM、22项脚本、API34完整43项设备检查通过。详情见[P2_REVIEW.md](P2_REVIEW.md)。按用户指示改用1.2.1发布线，远端验证和发布证据见RELEASE_1.2.1_REVIEW.md；真实手机能耗/轴向仍待验收。
