# 1.4.5 云母、GPU 淡化与构建门禁发布审阅

源码基线为 `d79fc1d6df3c38d29c03d293c175f17bbb911fb2`。本次分批提交云母材质、GPU 修复、构建门禁优化和版本发布记录；保留原有 Compose 方案草稿，不改写历史发布审阅。

## 行为与兼容性

- 新增独立可选 `LumenMicaBackdrop`／`LumenMicaImage`：Base／BaseAlt、静态背景预处理、主题色调、内容／命令／卡片层、失焦淡化与辅助功能／省电／内存回退。配方来源、Android 适配范围和预算见 `MICA_MATERIAL.md`。
- Mica 由宿主显式安装，不改写既有 `SkinId` 或偏好协议。单快照最多 36 KiB，每窗口当前快照与着色副本合计最多 72 KiB；绘制不重新采集或模糊背景。
- API 33+ 局部磨砂节点在关闭折射时，以零折射强度复用既有磨砂 shader，在淡化前显式执行 SDR 预乘钳制。API 31–32 继续使用颜色矩阵。颜色增益常数不变；饱和色参与透明混合时与直接着色路径的 SDR 语义一致，不再保留大于 alpha 的 RGB。
- 高级 AGSL 路径支持 `LINEAR`，hold／end 边界与纯策略一致；均匀变量更新不重新编译 shader。
- 没有增加生产依赖或改变旧公开入口。新增 API 按用户明确指定编号为 1.4.5（`VERSIONING.md` 的编号例外）；契约版本仍为 1，minSdk 27。

## 两项 GPU 失败的复现与处理

早期审阅快照 `MICA_BUILD_REVIEW_2026_10_15.md` 保留了当时的全量 140／142 结果。本次在未修改的 HEAD 独立包上再次复现两项失败，随后按实际像素诊断处理：

| 用例 | 确认原因 | 处理 |
|---|---|---|
| `linearGpuFadeHasUniformPixelCoverage` | 红色样本按 `1.08 × 255 + 10` 保留扩展范围后参与淡化：1/10 处为 255，1/2 处为 183；绿、蓝覆盖正确。旧文档记录了该设备的混合现象，本次进一步统一不同后端的 SDR 颜色边界 | 节点路径复用零强度 shader，在淡化前钳制；9 段 RGB 覆盖断言及 4 级误差不变 |
| `paddedExperimentCanReadTheOutsideMarkerAndReportsActualFiveBounds` | 标记和表面用固定 px，折射位移用 dp；密度 4 时位移越过 20px 标记，输入也因边距预算缩为 2 倍采样 | 测试固定像素位移，保留安全区蓝色、扩展区红色和五边界断言 |

另补齐 `linearEnhancedGpuFadeHasUniformPixelCoverage`，防止节点与高级路径对同一个 LINEAR 选项产生不同语义。新增三项源码契约守住钳制阶段、版本隔离和曲线接线。修复后两项原始失败定向通过，包含 GPU、云母、亚克力和滚动采样的 33 项相关设备回归全部通过。

## 门禁与构建优化

- Demo 一次构建，按不可变 revision 与 SHA-256 分发同一 APK 对到 API 27／31／33／34；通过后发布同一份 APK。模拟器任务不再重复编译。
- 原有构建、JVM、Lint、AAR／源码包与 R8 在同一任务图执行，许可证直接检查已构建输出。
- 严格配置缓存，源码契约输入显式登记。已用“只追加注释、字节码不变”的探测证明测试仍失效重跑。
- 逐条设备协议／XML 校验，完整身份、数量和终止状态检查；失败不自动重放。详情见 `BUILD_WORKFLOW.md`。

本地无变更、同一完整任务图对比为 50.19 秒 → 29.44 秒；20,096 条合成报告的 Python 跟踪峰值分配约 12.35MB → 7.49MB。它们是本地构建／日志基准，不代表 hosted CI、设备功耗或 OEM 等价性。
