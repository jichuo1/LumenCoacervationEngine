## 范围和顺序

1. D01—D06：来源许可与产物检查、来源/代理/效果计数、固定场景基准、五类采样范围实验、来源代次/可用性、依赖与生命周期校验。
2. D09/D15/D16：统一四角与形状描述、语义材质及尺度归一化、预乘透明度契约。
3. D07/D08：显式背景推广和固定两级渐进模糊，保留已有来源和低版本回退。
4. D10—D13：两形状融合与解析梯度、真实选择器接入、局部按压、变换驱动光源。
5. D17—D19：内部效果实例/阶段、每表面细节预算、固定时钟/种子/版本化参数回放。
6. 构建、行为与源码契约、低版本DEX、设备像素、同场景性能与最终Review。

P2的传感器、粒子、动画资产、Compose适配，以及NativeBackdrop/Mesh观察项不属于本轮P1范围。

## 调节与兼容原则

- 新效果独立启停，保留旧配置和材质持久化标识；实验性采样路径默认关闭。
- 调节按强度、作用范围、更新率和资源预算组织；输入拒绝非有限值和越界。
- 连续交互状态通过原始数值更新，复用现有可打断动效；不为触点移动逐帧构造RenderEffect。
- 公开旧构造、默认参数和方法描述符保留；新增能力使用新配置/重载，契约版本仍为1。
- 保护来源、生命周期、缓冲上限和失败单向降级保持为硬约束。
- 原热策略保持原义；新细节策略独立且有滞回与驻留时间。
- Demo提供参数与开关、确定性控制和元数据导出，默认不导出背景图片。
